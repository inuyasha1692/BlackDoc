# 双分区

在正文的插入菜单中选择“双分区”，然后在左右两侧编辑内容。首版面向 PC，保持左右排列，不支持嵌套双分区。

## 尺寸

- 拖动中间分隔线调整列宽。左侧占比范围为 25% 到 75%。
- 右侧高度预设为小（240px）、中（400px）、大（640px）。
- 拖动右侧底部手柄或输入像素值，可以在 160px 到 1200px 之间调整高度。
- 分隔线聚焦后可用方向键调整，Home / End 可切换到最小或最大值。
- 宽度和高度随文档保存。拖动完成计为一次修改，可撤销。
- 左侧完整展开，整体区域高度取两侧较高者。

## 阅读和编辑

鼠标在右侧时优先滚动右侧内容，到顶部或底部后继续滚动页面。鼠标位于其他区域时直接滚动页面。表格、画布等内部控件保留自身交互。

两侧的标题都会进入大纲，顺序为左侧全部标题、右侧全部标题。点击右侧标题时，页面和右侧滚动区域同时定位。

导出 HTML 沿用保存的宽度和高度，右侧可独立滚动，不显示尺寸编辑控件。打印时展开右侧全部内容。

删除有内容的双分区前需要确认。撤销会恢复两侧内容及尺寸。

## 验收

使用功能展示示例中的“双分区”章节检查：

1. 编辑左右内容，添加标题、表格、媒体或画布。
2. 调整列宽与右侧高度，分别撤销、重做，再保存和重新打开。
3. 在右侧中间、上下边界及左侧滚动，检查页面滚动的衔接。
4. 从大纲定位右侧靠后的标题。
5. 删除双分区，取消删除、确认删除并撤销。
6. 导出 HTML，检查尺寸、内部滚动、大纲定位和打印展开。
